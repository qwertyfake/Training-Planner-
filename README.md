## Описание программы

Training Planner — GUI-приложение на Python с использованием Tkinter.

Функции программы:

- Добавление тренировок
- Просмотр тренировок
- Фильтрация по типу тренировки
- Фильтрация по дате
- Сохранение данных в JSON
- Загрузка данных из JSON
